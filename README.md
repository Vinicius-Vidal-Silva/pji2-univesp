# Plataforma de Compartilhamento de Livros 📚

## 📖 Sobre o Projeto
Este repositório contém o código-fonte e a documentação do projeto desenvolvido para a disciplina de **Projeto Integrador em Computação II** da Univesp[cite: 1]. 

O problema central que buscamos resolver é a dificuldade de acesso a livros e a falta de mecanismos simples para que pessoas possam compartilhar, trocar ou disponibilizar livros que já não utilizam[cite: 1]. A ausência de uma ferramenta centralizada contribui para o desperdício de exemplares e para a redução das oportunidades de leitura, visto que muitas pessoas possuem livros em casa que poderiam ser aproveitados por outros leitores, mas não encontram uma forma prática de realizar esse compartilhamento[cite: 1].

## 🎯 Objetivo
Desenvolver uma plataforma digital que possibilite o compartilhamento de livros entre usuários, permitindo o cadastro de exemplares, a busca por livros de interesse e a interação entre pessoas interessadas em disponibilizar, trocar ou receber livros[cite: 1]. O projeto visa contribuir para o acesso e incentivo à leitura, a reutilização de exemplares e a formação de uma comunidade de leitores[cite: 1].

## 💻 Tecnologias e Ferramentas
O projeto foi estruturado para contemplar os requisitos de framework web, script web, nuvem, uso de API, acessibilidade e controle de versão[cite: 2]:

* **Front-end / Script Web:** JavaScript[cite: 2, 3].
* **Integração e Nuvem (BaaS):** Uso do Supabase para manter o catálogo de livros disponíveis em nuvem, controle de status (disponível, reservado, doado) e dados de contato[cite: 2, 6].
* **APIs Externas:** Integração com Google Books API ou Open Library API para autocompletar informações do livro (capa, sinopse, autor) a partir do título ou ISBN[cite: 2, 6].
* **Acessibilidade:** Inclusão de textos alternativos automáticos nas capas visuais via metadados da API e suporte estruturado para navegação por teclado[cite: 3, 6].
* **Controle de Versão:** GIT e GitHub[cite: 3].
* **Banco de Dados:** Utilização de tecnologias relacionais/nuvem para o armazenamento de dados da aplicação[cite: 2, 3].
